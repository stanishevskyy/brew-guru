# 📱 Brew Guru

A web application for discovering cafes and ordering food. Users can search for cafes, filter and sort results, view detailed cafe information, place food orders, and make table reservations. The application also supports favorites, reviews, user profile management, and viewing visit history.

---

## 🔗 Live Demo

[Demo](https://stanishevskyy.github.io/brew-guru/)

---

## ✨ Features

### 🔍 Cafe Discovery

- Search cafes by name
- Filter and sort cafes by different criteria
- View detailed information about each cafe

### 🍽️ Ordering System

- Add food items to cart
- Place orders directly from the cafe page

### 🪑 Table Reservations

- Reserve tables in selected cafes
- Manage reservation data

### ❤️ Favorites

- Add cafes to favorites
- Remove from favorites anytime

### 📝 Reviews System

- Add reviews for cafes
- Edit existing reviews
- Delete reviews

### 📜 Visit History

- Automatically saves cafe visit history when opening cafe details

### 👤 User Profile

- Edit personal information
- Manage user settings

---

## 🛠️ Technologies Used

- ⚛️ React — UI library
- 🟦 TypeScript — static typing
- 📦 Redux Toolkit (RTK) — state management
- 🌐 Fetch API — server communication
- 🧭 React Router — routing
- 🎞 React Hook Form — form handling
- 💅 CSS Modules / SCSS — styling

## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/stanishevskyy/brew-guru.git

# Navigate to project
cd brew-guru

# Install dependencies
npm install

# Run project
npm start
```

## 📌 Project Purpose

This project was built to practice modern React development including state management, routing, forms, and building a full-featured frontend application with real-world functionality like ordering, reservations, and user interaction systems.
